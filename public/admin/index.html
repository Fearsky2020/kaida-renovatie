发布新工程

照片、文字、短视频直接往里放。当前为 GitHub 验收模式；正式上线后接 Cloudflare D1 / R2。

1

上传工程照片

一次选择多张，第一张默认作为封面。正式版支持拖动排序和“设为封面”。

2

选择工程类型

3

写几句话 可不填

这里就是给他随便打字的地方。不需要排版，写施工内容、材料、客户需求、做法都行。

4

上传短视频 可不填

手机拍完可以直接上传。适合展示柜门开合、抽屉细节、灯光、施工过程和完工后的空间效果。

正式版上传后会自动压缩、生成网页播放格式和封面图；访客点开工程时可直接播放。

5

验收模式： 当前页面用于确认后台操作是否够简单。照片/视频只在本机预览，发布按钮不会把内容公开给客户；Cloudflare 阶段再接真实数据库与文件存储。
